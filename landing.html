01

问数与智库

智能知识库 / 数据问答系统
PythonLangGraphFastAPISSEQdrantElasticsearchMySQLVue 3

项目介绍

基于 LangGraph + FastAPI + SSE 的智能知识库系统：构建 meta 知识库，问答流程按节点流转，进度通过 SSE 实时流式推送到前端；底层接入 MySQL、Qdrant、Elasticsearch，统一以异步 repository 模式封装数据访问。

主要工作

  • 把一次问数拆成 11 个可观测节点：抽取关键字 → 召回列 / 指标 / 字段取值 → 合并召回 → 过滤指标 / 表 → 补充上下文 → 生成 SQL → 校验 SQL → 执行 SQL，出错能直接定位到节点。
  • 用 SSE 把每个节点的状态实时推给前端，答案逐段返回，首字等待时间明显下降。
  • 按场景选型存储：结构化数据走 MySQL，向量召回走 Qdrant，关键词检索走 Elasticsearch，统一封装异步 repository 访问层。
  • 实现文件导入与知识库构建闭环，支持文档上传、切分入库与答案来源回显。

02

电商运营助手

运营场景智能体
PythonFastAPITypeScriptNext.jsNode.jsDocker

项目介绍

面向电商日常运营场景的智能助手：整合商品、订单与客户数据，辅助运营人员做数据分析、话术生成与决策支持，减少重复劳动。

主要工作

  • 把单品运营做成一条闭环流水线：建档/SKU → 竞品 → 诊断 → 素材 → 投放 → 数据 → 复盘，每一环的完成状态在页面上直接可见。
  • 实现商品与 SKU 库存的流水登记，入库、锁定、预警分列，库存变化可回溯对账。
  • 图片与视频生成任务放后台队列执行，页面自动刷新状态，运营不必守着等结果。
  • 统一模型配置入口，按能力切换模型与参数，业务侧不感知底层差异。

03

智能客服系统

客服会话与话术管理系统
PythonFastAPITypeScriptJavaScriptMySQL

项目介绍

智能客服解决方案：包含客服后端服务与会话管理，支持话术辅助、会话流转与客户数据管理，帮助客服团队提效。

主要工作

  • 实现会话全生命周期管理：按 TURN 编号逐轮留痕，标注买家 → 应答台的流转方向与坐席身份，多轮上下文可回溯。
  • 会话与业务对象联动：右侧面板实时带出该客户的订单与商品（订单号、金额、待发货状态），客服可一键把商品卡片发给买家。
  • 话术库与智能推荐结合，客服在应答台一键取用，减少重复打字。
  • 前端按设计稿重构应答台与知识库页面，顶栏常驻服务探活指示灯，并同步处理打印场景的样式覆盖。

怎么做东西

后端不将就。存储按场景选型，访问层统一封装；前端只做一件事：把能力说人话。
