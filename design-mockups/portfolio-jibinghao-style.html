01

问数与智库

智能知识库 / 数据问答系统
PythonLangGraphFastAPISSEQdrantElasticsearchMySQLVue 3

项目介绍

基于 LangGraph + FastAPI + SSE 的智能知识库系统：构建 meta 知识库，问答流程按节点流转，进度通过 SSE 实时流式推送到前端；底层接入 MySQL、Qdrant、Elasticsearch，统一以异步 repository 模式封装数据访问。

简介沿用现有页面草稿，定稿前需你确认

主要工作

  • 设计问答流程的节点化编排，把检索、改写、生成拆成可观测的图节点，单步失败可定位到节点而不是整条链路。
  • 用 SSE 把阶段进度实时推给前端，答案逐段返回，首字等待时间明显下降。
  • 按场景选型存储：结构化数据走 MySQL，向量召回走 Qdrant，关键词检索走 Elasticsearch，统一封装异步 repository 访问层。
  • 实现文件导入与知识库构建闭环，支持文档上传、切分入库与问答来源回显。

02

电商运营助手

运营场景智能体
PythonFastAPITypeScriptNext.jsNode.jsDocker

项目介绍

面向电商日常运营场景的智能助手：整合商品、订单与客户数据，辅助运营人员做数据分析、话术生成与决策支持，减少重复劳动。

简介沿用现有页面草稿，定稿前需你确认

主要工作

  • 把上线前的准备动作收敛成四步引导（建店建档 → 导入数据 → 配置模型 → Agent 中心），新店铺从空库到可用有明确路径。
  • 实现商品与 SKU 库存导入，CSV 上传先预览校验、确认后只写入有效行，避免脏数据直接进库。
  • 统一模型配置入口，按能力切换模型与参数，业务侧不感知底层差异。
  • 搭建 Agent 中心，把日常运营动作沉淀为可复用、可审批的任务流。
