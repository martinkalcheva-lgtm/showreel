01

问数与智库

智能知识库 / 数据问答系统

打开演示

项目介绍

基于 LangGraph + FastAPI + SSE 的智能知识库系统：构建 meta 知识库，问答流程按节点流转，进度通过 SSE 实时流式推送到前端；底层接入 MySQL、Qdrant、Elasticsearch，统一以异步 repository 模式封装数据访问。

PythonLangGraphFastAPISSEQdrantElasticsearchMySQLVue 3

简介沿用现有页面草稿，定稿前需你确认

主要工作

  • 01设计问答流程的节点化编排，把检索、改写、生成拆成可观测的图节点，单步失败可定位到节点而不是整条链路。
  • 02用 SSE 把阶段进度实时推给前端，答案逐段返回，首字等待时间明显下降。
  • 03按场景选型存储：结构化数据走 MySQL，向量召回走 Qdrant，关键词检索走 Elasticsearch，统一封装异步 repository 访问层。
  • 04实现文件导入与知识库构建闭环，支持文档上传、切分入库与问答来源回显。
