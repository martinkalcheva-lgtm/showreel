这是为已经跑在线上的 4 套系统补做的一套界面设计稿，覆盖 4 个系统、共 12 个页面（另含本总览）。 全部页面共用同一份设计系统（design-system.css）：同一套配色、同一套字体分工、 同一批组件类，不允许任何一页私自定义颜色、圆角或阴影 —— 所以这 12 个页面并排看过去像一套东西，而不是 12 个网页。

设计系统说明

DESIGN SYSTEM v1
维度 规格
配色 暖纸底 / 碳素墨 / 工程朱红 / 信号翠绿，全部以 OKLCH 定义为单一色源；明暗双主题各一套变量，无第二处硬编码色值，零渐变、零辉光、零玻璃拟态。
字体 衬线标题（宋体系）+ 无衬线正文 + 等宽标签三轨分工；7 档字阶每一档都带 px 下限，保证投屏可读；汉字一律零字距，字距只放开在全大写拉丁标签上。
组件 面板 / 表格 / 徽标 / 标签 / 状态灯 / 运行轨迹 / 引用卡 / 空状态 / 表单 / 按钮，共 10 组现成类；1px 发丝线，圆角全局统一 2px，零投影。
响应式断点 1023 / 899 / 767 三档 + 横屏矮窗一档，数值由「每栏还能放多少中文字」推导而非设备宽度；侧栏在 899 折成横向滚动条；375px 下无横向溢出。
动效原则 160 / 260 / 420ms 三档缓动（进场 / 退场 / 状态 / 循环四组曲线）；无限动画仅限状态指示（状态灯/骨架屏/流式光标），总数 ≤ 3，禁止装饰性无限动画，且只动 transform 与 opacity；prefers-reduced-motion 下所有动效一次性降级为 0.001ms。

图标共 13 枚，24 网格 / 描边统一 1.5 / currentColor；零外部依赖：无 CDN、无 Web Font、无图标库。
