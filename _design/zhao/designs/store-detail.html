READING NOTES
时间范围
所有经营类数字必须写明起止日期，并注明是否含端点；未写明范围的对比一律不展示。
样本与覆盖
给出「覆盖商品数 / 总数」；覆盖不足时数值保留原样，但必须标注偏低或偏高方向。
未覆盖 ≠ 0
能力未开通或数据缺失显示「未覆盖」，不用 0 冒充。
环比基期
任何环比都注明基期区间，不写「提升了 N%」这种无基期表述。

本页为静态设计稿：店铺、账号、商品、库存与经营数字均为示意数据，不连接任何后端接口；所有颜色 / 圆角 / 字体 / 间距均取自 design-system.css 的 token。
